# Reproducing the paper

Every figure and table in the paper, the code that produces it, the data it
needs, and whether it can be reproduced from this repository today. Get the
datasets and weights first: [docs/datasets.md](docs/datasets.md).

Scripts run from the repository root with `python -m`. Notebooks run from
their own folder.

## Regenerating results

The benchmarks behind Table 1 and Figures 6 and 7, all eight datasets with
10 runs each:

```bash
bash run_all_benchmarks.sh
```

Or one dataset, for example:

```bash
python -m experiments.vision.mri_kl_benchmark \
    --methods baseline replace_mean patchcutout arch_mod temperature platt mcal_ce --runs 10
python -m experiments.tabular.ctg_kl_benchmark \
    --methods baseline replace temperature platt mcal_ce archmod retrain --n_runs 10
```

Each benchmark writes to its area's `results/` folder, for example
`experiments/vision/results/json/aggregated_results_mri.json`, which is
where Figures 6 and 7 read. Note that the vision benchmarks name their
methods `replace_mean` and `arch_mod`, and the tabular ones `replace` and
`archmod`.

The faithfulness experiments (LIME and SHAP faithfulness, deletion and
insertion) write to `experiments/results/`:

```bash
python -m experiments.run_faithfulness --dataset mri   # or breakhis, chexpert, ctg, physionet, breast_cancer
```

## Known gaps

1. **Figure 8 cannot be reproduced.** Its notebook reads
   `results/mcal_training_dynamics.json`, which is not in the repository;
   the notebook's saved output shows it was written on another machine. It
   also loads `saved_models/mri/vit_mri_ps32_ablate0.00_best.pth`, which is
   not listed with the other weights. The twelve output PDFs are committed
   in `experiments/results/`.

2. **Table 1 and Figures 6-7 read different runs.** For MRI, MedQA and
   PhysioNet they read different committed result files (table above), and
   the numbers in each pair disagree. The largest difference in a mean KL
   value, in each case for `mcal_ce`, is 6.7% for MRI, 50% for PhysioNet
   and 203% for MedQA. Regenerating both from one run would remove the
   contradiction.

3. **Most Table 1 values are not in the committed results.** Of the 56
   values in Table 1 (arXiv 2603.04831v1), 14 are within 1% of a committed
   result file and 10 more within 5%; 11 are for methods absent from the
   committed files, and 21 differ by more than 5%. CTG matches exactly and
   BreakHis closely. Brain MRI and CheXpert are close except for the MCal
   and Retrain or PlattCal columns. PhysioNet, MedQA, MedMCQA and breast
   cancer do not match. Table 1 reports the argmax (one-hot) KL.

   Rerunning the PhysioNet benchmark with the committed settings (10 runs,
   10 fractions, 1,000 samples) reproduces the committed PhysioNet results
   within run-to-run noise, but every value is 1.4 to 3.1 times the value in
   the paper, and MCal (1.56e-2) no longer beats Retrain (1.51e-2). The
   benchmark does not seed its randomness, so reruns match statistically,
   not digit for digit.

4. **Not every Table 1 row comes from code in the repository.**
   `notebooks/plot_all_results.ipynb` reads MRI, BreakHis, CheXpert,
   PhysioNet and MedQA only. `results/json/aggregated_results_ctg.json` has
   all seven CTG methods but no notebook reads it. For breast cancer,
   `results/json/aggregated_results_breast_cancer.json` contains only
   `baseline` and `temperature`, and `breast_cancer_detailed_results.json`
   adds `mcal`, `mcal_ce`, `platt` and `retrain`; no committed file has the
   replacement or architecture results the paper reports for it. MedMCQA
   results are in `results/json/aggregated_results_medmcqa.json`.

5. **Weights are not hosted.** The Vision Transformer checkpoints behind the
   vision benchmarks and Figures 5 and 11 are not publicly available yet.
   Their checksums are in [docs/datasets.md](docs/datasets.md).

6. **Local data copies differed.** Some experiments read the MRI and
   BreakHis images from `data/`, others from `experiments/vision/data/`,
   and the development copies in those two places were not the same
   (details in [docs/datasets.md](docs/datasets.md)).
